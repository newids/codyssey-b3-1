# 평가 대비 체크리스트 — 요구사항 ↔ 증빙 매핑

평가자는 미션 문서의 "최종 결과물"과 "기능 요구 사항"을 그대로 채점표로 쓴다고 가정한다.
각 행의 **증빙** 이 저장소 안에 실제로 존재해야 ✅ 를 찍는다.

## C. 제약 사항

| 제약 | 확인 방법 | 상태 |
|---|---|---|
| 프리 티어 범위 | t2/t3.micro, EBS ≤10GiB, NAT/ELB/RDS 미생성. Billing Free Tier 페이지 | ☐ |
| 루트 계정 미사용 | 모든 콘솔 스크린샷 우상단 계정명이 `b3-1-operator @ 계정ID` | ☐ |
| 서울 리전 | 모든 스크린샷 우상단 "Asia Pacific (Seoul)" | ☐ |
| 키페어 1개, 안전 보관 | `.pem` 이 저장소에 없음 (`git ls-files | grep pem` 결과 없음) | ☐ |
| 실습 후 전부 삭제 | `scripts/check-leftovers.sh` 출력 전부 0 | ☐ |

## E. 감점 위험 (자주 틀리는 것)

- [ ] 스크린샷에 **액세스 키/시크릿** 이 찍혀 있음 → 즉시 키 비활성화·재발급
- [ ] README 의 IP 와 스크린샷 IP 가 다름 (인스턴스 재생성 후 README 미갱신)
- [ ] 트러블슈팅이 "증상·조치"만 있고 **가설·검증·재발방지** 가 비어 있음
- [ ] 정리 체크리스트에 체크만 있고 **근거(스크린샷/명령 출력)** 가 없음
- [ ] 인스턴스를 Terminate 가 아닌 **Stop** 만 함 → EBS 과금 지속
- [ ] "VPC and more" 마법사로 만들어 NAT Gateway 가 생성됨 → 시간당 과금
- [ ] 다이어그램에 트래픽 흐름(화살표)이 없음
- [ ] 보너스(Docker) 선택 시 README 에 이미지명·실행 방식·포트 매핑·스크린샷 2장 중 하나라도 누락
